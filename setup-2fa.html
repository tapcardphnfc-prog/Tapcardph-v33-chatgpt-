📧 STEP: Enable Gmail Order Notifications

Tapcard PH NFC can send you real-time Gmail alerts for every new order, payment submission, and customer message. To activate, you need a Gmail App Password — a one-time code Google generates so this app can send emails on your behalf safely.

  1. Go to myaccount.google.com/security
  2. Enable 2-Step Verification if not already on
  3. Search for "App Passwords" in the Google Account search bar
  4. Under App name, type: Tapcard PH NFC
  5. Click Create — Google shows you a 16-character password
  6. Copy it and open .env in your project folder
  7. Set GMAIL_USER=your@gmail.com and GMAIL_PASS=xxxx xxxx xxxx xxxx
  8. Restart Node.js: node server.js

See .env.example in your project folder for a full template.
